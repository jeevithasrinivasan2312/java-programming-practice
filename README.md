# Java Programming Practice

A structured collection of Java programming exercises covering fundamentals, problem-solving, core Java concepts, and interview-oriented coding practice.

## About This Repository

This repository contains my hands-on Java practice programs, developed progressively from basic programming concepts to advanced Java features.

The goal is to strengthen:

- Java programming fundamentals
- Problem-solving and logical thinking
- Edge-case and boundary-value analysis
- Time and space complexity awareness
- Clean and readable coding practices
- Interview preparation for QA Automation / SDET roles

## Learning Approach

For each program, I focus on:

1. Understanding the problem
2. Writing the solution independently
3. Testing normal and edge cases
4. Applying Equivalence Partitioning (EP) and Boundary Value Analysis (BVA) where applicable
5. Reviewing time and space complexity
6. Improving code quality and readability
7. Considering interview-oriented follow-up questions
